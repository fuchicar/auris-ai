01 · contexto

Invertir bien es difícil. Las herramientas no ayudan.

✗

Asesoramiento inaccesible

El asesoramiento financiero profesional es caro y está fuera del alcance del inversor particular. La alternativa habitual: foros, vídeos y decisiones a ciegas.

✗

Información fragmentada

Cotizaciones en una web, fundamentales en otra, la cartera en una hoja de cálculo y las noticias en un tercer sitio. Nada conversa entre sí.

✗

Los LLM «a pelo» alucinan

Un chatbot genérico inventa precios, fechas y ratios con total confianza. No tiene datos de mercado reales ni una calculadora fiable: hace las cuentas «de memoria».

✗

Privacidad comprometida

Volcar tu situación patrimonial en un servicio en la nube significa ceder tus datos financieros más sensibles a un tercero.

02 · propuesta

Auris: el LLM razona, Go calcula

Un agente ReAct en terminal que combina el razonamiento de un LLM con datos de mercado reales y un motor de cálculo determinista escrito en Go. El modelo decide qué calcular; el código decide cuánto da.

✓

Datos reales, no recuerdos

Cotizaciones, velas, fundamentales, dividendos y noticias llegan por API de proveedores de mercado. El LLM nunca «recuerda» un precio: lo consulta.

✓

Ni un número inventado

VaR, Sharpe, DCF, Monte Carlo… 57 herramientas deterministas y testeadas ejecutan cada cálculo. La aritmética jamás sale del modelo.

✓

Local-first

Configuración cifrada en tu disco y opción de inferencia 100 % local con Ollama: tus finanzas no tienen por qué salir de tu máquina.

razonamiento LLM + datos de mercado + cálculo en Go = Auris

Patrón driver: cualquier LLM, cualquier mercado

// pkg/llm — una interfaz, N proveedores
type AIProvider interface {
    Connect(ctx) error
    ListModels(ctx) ([]Model, error)
    Complete(ctx, req) (Response, error)
    Stream(ctx, req) (<-chan Chunk, error)
}

// conformidad verificada en compilación
var _ llm.AIProvider = (*Driver)(nil)
  • Errores sentinel compartidos (ErrRateLimit, ErrNotSupported…): la TUI reacciona igual sea cual sea el proveedor.
  • Stream garantiza cierre de canal tras Done: los consumidores hacen range sin fugas.

08 · fiabilidad numérica

Un motor cuantitativo que no alucina

  • Monte Carlo (GBM) hasta 100.000 trayectorias con percentiles de resultado.
  • VaR paramétrico e histórico; stress testing por shocks.
  • Valoración: DCF con valor terminal, múltiplos, P/FCF, PEG.
  • Riesgo y rendimiento: Sharpe, beta, volatilidad, max drawdown, CAGR, P&L.
  • Técnico: RSI (suavizado de Wilder), MACD, Bollinger, SMA/EMA, matriz de correlaciones.

09 · gestión patrimonial

Carteras de verdad: lotes, FIFO y rebalanceo

Contabilidad por lotes (FIFO)

Cada compra es un lote con fecha y precio. Las ventas consumen lotes en orden FIFO y devuelven el P&L realizado exacto, con el detalle de qué lote se consumió.

Historial de transacciones

6 tipos — compra, venta, dividendo, depósito, retirada y ajuste — registrados y consultables desde la TUI y desde el propio agente.

Métricas de cartera

Valor actual, pesos por símbolo, P&L realizado y latente, dividend yield, beta agregada y concentración HHI con interpretación por tramos.

Rebalanceo sugerido

Defines una asignación objetivo; Auris detecta la desviación y propone las operaciones concretas para volver al plan, respetando un umbral de tolerancia.

Todo es accesible por chat: «vende 10 AAPL», «registra el dividendo de MSFT», «¿me desvié de mi 60/40?» — el agente opera la cartera con sus 16 tools de portfolio.

  • Tests de integración honestos: se saltan solos (t.Skip) si no hay credenciales; la suite corre limpia en cualquier máquina y en CI.

12 · ética

IA responsable, por diseño y por contrato

⚠ Aviso importante sobre el uso de IA

Esta aplicación usa inteligencia artificial para ayudarte a gestionar y analizar información financiera. Los modelos de IA pueden producir respuestas incorrectas o incompletas, incluso con aparente seguridad. Esta herramienta no sustituye en ningún caso el consejo de un profesional financiero regulado.

Escribe «sí» para confirmar que has leído y entendido este aviso: sí▌
  • Consentimiento informado obligatorio: el disclaimer bloquea el primer arranque hasta confirmarlo explícitamente.
  • Posicionamiento honesto: «para explorar ideas, no para decidir tu dinero».
  • Mitigación estructural, no solo textual: el riesgo de alucinación numérica se elimina delegando toda la aritmética al motor determinista.
  • Transparencia: cada consulta de datos y cada cálculo se muestran en pantalla (⚙) mientras ocurren.
13 · visión

Diseñado para crecer

› Más mercados y brókers

El patrón driver hace que integrar un nuevo proveedor de datos —o la API de un bróker para operar— sea un paquete aislado, sin tocar el núcleo.

› Streaming en el chat

La TUI ya muestra las respuestas del LLM token a token en los 4 drivers, incluyendo llamadas a herramientas dentro del streaming — sin esperas a ciegas ni con modelos locales.

› Alertas y vigilancia

Sobre la suscripción de cotizaciones ya implementada: avisos por precio, deriva de la asignación objetivo o eventos corporativos.

› Más clases de activo

El modelo de datos (AssetType) ya contempla más allá de la renta variable: fondos, ETFs, cripto y renta fija como evolución natural.

Nada de esto exige rediseñar: las abstracciones ya lo soportan.
