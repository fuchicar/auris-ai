## 🧰 Tier 1 (histórico) — Imprescindibles para el TFM (predicción + análisis técnico)

Completado el 2026-06-29.

- [x] **MATH-1** `calculate_sma` — Media móvil simple. Params: `prices[]`, `period` (int). Devuelve serie de SMAs y resumen (último valor, último vs anterior). Base para cruces, Bollinger y MACD. ✅ Implementado 2026-06-29.
- [x] **MATH-2** `calculate_ema` — Media móvil exponencial. Params: `prices[]`, `period` (int), opcional `alpha` (float, default 2/(period+1)). Devuelve serie de EMAs y resumen. ✅ Implementado 2026-06-29.
- [x] **MATH-3** `calculate_rsi` — Relative Strength Index (Wilder). Params: `prices[]`, opcional `period` (int, default 14). Devuelve `rsi_value`, `interpretation` ("sobreventa <30", "neutral", "sobrecompra >70") y serie histórica. ✅ Implementado 2026-06-29.
- [x] **MATH-4** `calculate_macd` — MACD. Params: `prices[]`, opcionales `fast_period` (12), `slow_period` (26), `signal_period` (9). Devuelve `macd_line`, `signal_line`, `histogram` y sus series. Interpretación: cruce alcista/bajista. ✅ Implementado 2026-06-29.
- [x] **MATH-5** `calculate_bollinger_bands` — Bandas de Bollinger. Params: `prices[]`, opcionales `period` (20), `num_std` (2). Devuelve `upper`, `middle`, `lower` por punto + `bandwidth` + `%b` (posición del precio dentro de la banda). ✅ Implementado 2026-06-29.
- [x] **MATH-6** `calculate_correlation_matrix` — Matriz de correlaciones. Params: `series` (map[string][]float64, al menos 2 series de igual longitud). Devuelve matriz simétrica NxN con correlaciones de Pearson e interpretaciones ("fuerte", "moderada", "débil"). Base para análisis de diversificación. ✅ Implementado 2026-06-29.
- [x] **MATH-7** `portfolio_calculate_metrics` — Métricas agregadas de cartera. Params: `portfolio_id` (opcional). Lee de `pkg/portfolio`. Devuelve: valor total a precio actual (requiere quotes vía market provider), P&L realizado vs latente, P&L % total, concentración (peso por posición + HHI), dividend yield ponderado, β ponderado (si hay benchmark). **Esta tool es el puente entre `pkg/portfolio` y el agente**. ✅ Implementado 2026-06-29.

**Decisión de diseño cerrada (DD-1, 2026-07-02 — ver `doc/adr.md`)**: los indicadores técnicos (MATH-1..5) reciben `prices[]` directamente. El LLM encadena `market_get_candles` → `calculate_*`. Razón: tests puros sin provider dependency y más control sobre la serie analizada.

**Nota técnica importante**: las series de salida con warm-up (SMA, RSI, Bollinger) usan un tipo `FloatSlice` que serializa NaN/±Inf como JSON `null`. Sin esto `json.Marshal` fallaría en silencio (`b == nil`) y la tool devolvería string vacío. Aplica a cualquier campo que pueda contener valores no finitos.

Implementación:
- `pkg/agent/math.go` → `calcSMA`, `calcEMA`, `calcRSI`, `calcMACD`, `calcBollingerBands`, `calcCorrelationMatrix`, helpers (`Float`, `FloatSlice`, `pearson`, `emaSeries`).
- `pkg/portfolio/metrics.go` (nuevo) → `Quote`, `PortfolioMetrics`, `SymbolWeight`, `ComputeMetrics`. Helpers `round2`/`round4` duplicados para evitar import cycle.
- `pkg/agent/tools.go` → 7 schemas en `buildTools()` + dispatch + `portfolio_calculate_metrics` con auto-fetch vía `market.GetQuote` (DD-2: auto-fetch es el default).
- `pkg/agent/agent_test.go` → `TestBuildTools_Count` actualizado 33 → 40. `mockMarket` ampliado con `quotesBySymbol`/`quoteErrBySymbol` para tests de dispatch con precios por símbolo.
- 52 tests nuevos pasan en verde (`pkg/agent` + `pkg/portfolio`).
